# $oyuz|BETA -- Telegram Bot

Бот для продажи чита **$oyuz|BETA** с оплатой через **USDT (TRC20)** via CryptoBot.

## Функции

- **Регистрация** -- автоматическая генерация логин:пароль при первом запуске
- **Оплата** -- USDT (TRC20) через CryptoBot API ($5)
- **Выдача лоадера** -- после оплаты бот отправляет файл лоадера
- **Мой профиль** -- статус подписки, HWID, смена пароля
- **HWID привязка** -- 1 ПК = 1 аккаунт (привязка при первом входе в лоадер)
- **Админ-панель** -- список аккаунтов, статистика

## Установка

```bash
cd bot
pip install -r requirements.txt
copy .env.example .env
```

Открой `.env` и укажи токены.

## Запуск

```bash
python main.py
```

## Структура БД

### Таблица `accounts`
| Поле | Описание |
|------|----------|
| `login` | Уникальный логин (oyuz_xxxxxx) |
| `password_hash` | SHA256 хеш пароля |
| `hwid` | HWID ПК (привязывается при первом входе) |
| `is_paid` | 0/1 -- оплачен ли доступ |
| `subscription_expires` | Дата истечения подписки |

## Поток пользователя

1. `/start` -- создаётся аккаунт с логином:паролем
2. Нажимает **Купить** -- создаётся инвойс
3. Оплачивает USDT -- бот проверяет статус
4. При подтверждении -- отправляется **лоадер**
5. Пользователь запускает лоадер -- вводит логин:пароль
6. Лоадер отправляет HWID -- бот привязывает к аккаунту
7. Профиль показывает статус, HWID, кнопку смены пароля

## Лоадер (нужно реализовать)

Лоадер должен:
1. Запрашивать логин:пароль у пользователя
2. Генерировать HWID (через `wmic` или GUID диска + MAC)
3. Отправлять `POST /api/login` с логином, паролем и HWID
4. При первом входе сервер привязывает HWID
5. При повторных входах -- проверять совпадение HWID
